# Supermarket game prototype

A Godot 3D supermarket prototype with shopping objectives, customer interactions, and a first-person player.

## Explore the project

- `main_menu.tscn` is the configured entry scene.
- `scripts/game_manager.gd` coordinates game state.
- Player movement and interaction live in `scripts/`.
- The project includes supermarket scenes, assets, and Blender source files.

## Run locally

Open `project.godot` in Godot 4.5 or a compatible version, allow asset imports to finish, and press **F5**. Blender source assets may require a configured Blender executable during import.

This repository is a development prototype. No browser build or public play URL has been verified for this checkout.
